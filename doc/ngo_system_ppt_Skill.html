報名付款

報名確認頁

/course/<hash_course>/pay/
  • 顯示課程名稱及費用摘要
  • 確認報名前最後確認頁
  • 點擊後導向 Stripe 付款
學生
報名付款

課程額滿

/course/<hash_course>/
  • 報名人數達上限時自動顯示
  • 學生無法繼續進行報名
  • 動態狀態由系統即時計算
學生
報名付款

Stripe 信用卡付款

/course/<hash>/pay/ → Stripe
  • Stripe 託管安全付款頁面
  • 支援 Visa / Mastercard 等
  • 本系統不儲存任何信用卡資料
  • 付款完成後 Webhook 回調確認
學生
報名付款

報名成功

/payment_successful/?session_id=...
  • Stripe Webhook 確認付款
  • 自動建立報名記錄
  • 自動發送確認 Email
  • 收據可在儀表板下載
學生
報名付款

付款失敗

/payment_fail/
/stripe/webhook/
  • 付款未成功時顯示失敗提示
  • 提示學生重試或聯絡中心
  • Stripe Webhook 監聽所有付款事件
